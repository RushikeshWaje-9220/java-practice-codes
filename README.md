## 🔧 How to Run

**Compile any file:**
```bash
javac FileName.java
```

**Run:**
```bash
java FileName
```

**Example:**
```bash
javac OOP.java
java OOP
```

> Requires **JDK 8 or above**. Download from [java.sun.com](https://www.oracle.com/java/technologies/downloads/)

## 💡 Key Concepts Demonstrated

- **Inheritance** — Single, Multilevel, Hierarchical
- **Polymorphism** — Method Overloading and Overriding
- **Abstraction** — Abstract classes and Interfaces
- **Encapsulation** — Access modifiers, Getter/Setter
- **Exception Handling** — try/catch/finally, user-defined exceptions
- **Multithreading** — Thread class, Runnable interface, synchronization
- **Collections** — ArrayList, HashMap, LinkedList, Iterator
- **File I/O** — FileWriter, FileReader, BufferedReader
- **GUI** — AWT Components, Event Handling, Calculator app
- **Networking** — Socket programming, Client-Server model
